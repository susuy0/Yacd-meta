# 短信 / Futoon chat v0.8.5

Telegram 聊天内的 Android 原生悬浮面板，包含「识别 / 订单 / 商户 / 结算 / 更多」五个独立 Tab。

v0.8.1 新增悬浮窗与外观自定义、相册图片入口、状态恢复、业务回复模板及按群自动化；设置顶栏复用 Telegram 原生组件，移除订单与凭证中的内部备注入口。设置入口、默认值和运行范围见 [EXTENSIONS-v0.8.1.md](EXTENSIONS-v0.8.1.md)。

v0.8.2 修复群自动化和扩展设置在刷新、选群返回时显示两次 `The coroutine scope left the composition` 的问题。已取消的读取不会更新错误和加载状态；真正的读取、保存失败仅显示一次并保留重试入口，保存失败后保留已编辑的规则。

## 会话商户与群多通道快捷栏

v0.8.5 在聊天输入框上方提供商户与通道快捷操作。私信使用对方 TGID，工单话题复用原 FutoonIdentity 提取标题末尾 TGID，查询后台精确商户。显示名称、商户 ID 和 TGID，直接打开「编辑商户 / 商户订单 / 结算 / 域名审核」。商户编辑使用原安卓表单及保存流程；三个列表固定当前商户，重置筛选、搜索、翻页和域名添加不扩大到其他商户。

一个群可手动勾选并保存多个支付通道，群内话题共用关联；切换话题只更新当前商户身份。支持添加、移除、全部通道或单通道筛选。全部通道订单按通道分组分页读取，成功率逐个通道对比，编辑前选择具体通道。旧版单通道与话题关联合并迁移，显式清空不会恢复旧数据。

FutoonPay 设置 → 会话快捷栏可管理开关、关联与默认统计时间窗。账号、后台地址、群和私信分别隔离，异步旧结果不能覆盖新对象。快捷栏使用原生 View；聊天栏不定时轮询，统计仅在面板可见时每30秒刷新，慢请求不会被定时刷新反复取消。保留原发送、媒体、快速回复、识别、商户、订单、结算和更多模块。详情见 [CHANNEL-SHORTCUTS.md](CHANNEL-SHORTCUTS.md)。

## 保留的裁剪范围

v0.8.3 移除聊天附件、头像与背景里的拍照入口、外部相机 Intent、内置拍照/录像实现、位置分享、实时位置上报、场所搜索与 Google 定位 SDK。视频剪辑、滤镜、特效及视频编辑模式关闭；图片裁剪、标注、相册选图、付款凭证、收到的地图消息查看与已有视频播放保留。已有视频可通过系统文件选择器发送。

所有清单变体排除相机、录音、精确/粗略/后台/媒体定位、视频媒体库和对应前台服务权限。动态权限请求统一过滤，混合请求保持原权限索引与拒绝结果；机器人网页直接返回不授权，二维码改用图库识别。音乐、通知和图片权限保持原有流程。

## 聊天工具

应用名称为「短信」，聊天首页标题为「Futoon chat」。普通 Telegram 用户资料显示完整 Telegram ID，点击可复制。

Telegram 主设置新增「FutoonPay 设置」，包含会话 Tag、快速回复和开户文案模板。Tag 按完整 TGID 匹配，显示在聊天列表会话名和聊天顶部；工单话题复用末尾 TGID 识别。设置按登录的 Telegram 用户隔离保存。

长按发送键打开快速回复，按 Tab → 分类 → 文案切换；文案插入当前输入位置，可继续修改后手动发送。空输入时也保留入口，原发送选项仍可打开。设置中支持新增、编辑、删除 Tag、Tab、分类和文案，删除分类/Tab 前确认。

## 识别、查单与付款凭证

复用 v0.5 的 FutoonQuery 和精确查单逻辑；选中文字、整条/多条消息、粘贴文本及截图 OCR/二维码内容均进入完整候选列表。候选支持校对、类型选择、勾选、逐项查询、取消未执行项、失败重试、分组、导出、异常汇总、历史与收藏。

用户所说的“补单”是凭证协助流程：聊天「富通查询」→ 选择命中订单 → 选择付款凭证 → 编辑图片/说明 → 用户手选联系人、群或话题 → Telegram 原生预览发送。该流程不会自动调用后台 fillorder 或修改支付状态。

长按聊天图片「作为富通凭证」可继续添加图片。说明模板包含查单、补单、回调异常、退款核实；订单信息、图片、处理状态和草稿均可恢复，发送状态读取 Telegram 的真实确认事件。多条消息分别记录来源；延迟图片、账号/后台变化以及订单切换均有隔离检查。

## 当前商户与完整商户管理

话题格式 `工单12627|游客|诺诺永久在𝕏|5824870757` 取末尾 TGID，私聊取对方 TGID；仅接受唯一精确匹配。可手动按 TGID/PID 切换、恢复自动识别，在普通群记住或解绑商户。

识别页的商户卡片与商户 Tab 均可直接编辑商户，使用原 FUTOON PAY Android 1.3.4 的 MerchantProfileDialog/Screen、AppViewModel 和表单校验/提交流程。也可调整余额、账号/支付/结算状态、用户组、重置密钥，查看订单、结算、流水、统计和域名审核。

商户 Tab 包含当前会话与全部商户两种视图；完整列表保留原版搜索、筛选、分页、详情、多币种余额、流水曲线、多选及批量功能。

订单、结算和“更多”的各模块继续直接使用原安卓组件及业务代码。业务界面不使用 WebView/HTML，不启动独立管理 Activity。提醒和独立工作台不在范围内。

## 商户开户

识别页商户卡片和商户 Tab 提供「商户开户」。原生控件读取后台 `uset.php?my=add` 的实际字段与最新用户组/结算方式，不嵌入网页。核对后仅提交一次 `POST ajax_user.php?act=addUser`；登录密码可留空，备注必填。结算模式 **D0 → settle=1（开启）**、**D1 → settle=0（不开启，默认）**；与手续费扣除模式 `mode` 分开。

创建成功读取返回的 uid/key，再用 `GET ajax_user.php?act=bind&uid=...` 读取完整 `bind` 链接。链接失败只重取链接；开户超时/结果不明时停止提交并提示查询核对。邮箱有唯一精确命中时阻止重复开户。

FutoonPay 设置 → 开户文案支持整段编辑与恢复默认。变量为 `{商户ID}`、`{密钥}`、`{网站域名}`、`{结算账号姓名}`、`{结算周期}`、`{绑定链接}`。使用本次提交值和后台返回值生成文案，按账号、后台、私聊/群及话题检查后填入输入框；保留已有草稿的其他文字，允许修改后手动发送。不会复用示例凭据。开户结果只保留在当前面板内存，不写入设置或日志。
