# VineChat FUTOON 原生悬浮面板

FUTOON 业务界面使用 Android Jetpack Compose，直接嵌入 Telegram 当前聊天上方的悬浮容器。订单、结算、“更多”及其子模块在同一个原生导航栈内切换，不启动独立管理 Activity。

- 订单：筛选、详情、通道查询、通知、冻结、退款和图片凭证。
- 结算：列表、筛选、处理中、完成及失败理由。
- 更多：商户 TGID 查询、支付通道、支付方式、轮询、监测、代理、域名、风控、黑名单、资金、分账、企业付款和系统设置。
- 后台动态表单、插件账户字段、轮询成员及配置子栏目均使用原生控件。
- 所有写操作先显示原生确认框；图片发送仍由用户选择 Telegram 收件人并确认。

业务模块不包含 WebView、JavaScript、HTML 或 CSS 资源。会话仍按 Telegram 账号和后台地址加密隔离。

测试不连接真实付款后台，不执行真实资金操作或 Telegram 消息发送。完整构建后仍需真机和实际后台联调。

提醒、盯单通知和独立工作台不在本次范围内；Telegram 原有消息通知及推送保留。
